# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub's Report a vulnerability form](https://github.com/apostelis/human-pace/security/advisories/new).
Do not publish vulnerability details in public issues or pull requests before
we have had a chance to investigate and coordinate a fix.

Include the affected Human Pace version or commit, host application and operating
system, steps to reproduce, potential impact, and a minimal proof of concept if
available. Remove credentials and personal information from attachments and logs.

Reports are reviewed by the maintainer. We will coordinate next steps and any
public disclosure through the private report. There is no guaranteed response
time or bug bounty.

For ordinary bugs without a security impact, use the
[bug report form](https://github.com/apostelis/human-pace/issues/new?template=bug_report.yml).
