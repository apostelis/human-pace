---
description: Open an interactive Human Pace formatting preview in your browser
allowed-tools: Bash(python3:*)
---
Run `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/preview.py" --open` with Bash to open the local interactive preview. Tell the user that preview controls do not save settings; apply their choices in the plugin's Configure options dialog, with Configuration source set to native. If the browser does not open, give them the generated HTML path. Do not apply human-pace formatting to this response.
